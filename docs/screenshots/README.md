## Updating the gallery

Keep descriptive lowercase filenames and use PNG or WebP for readable interface
text. Prefer captures of the standalone app with demonstration data. Check that
credentials or private content are not visible before committing. Record the
capture date or application version and update captions when the UI changes.
Keep the root README dashboard preview and this gallery in sync with the files.
