# Tests that are ALLOWED to skip, one `Class::method` per line.
#
# The CI step "Refuse a suite that skipped" fails on any skip that is not listed here.
# A bare count would not do: it lets a deliberate skip be silently traded for an
# accidental one, which is exactly the failure this guard exists to catch.
#
# ## Why the guard exists (measured 2026-09-22)
#
# `php artisan test` reported "36 passed" on a machine where **62 of 98 tests skipped**,
# because `ext-pdo_sqlite` — a declared requirement in `composer.json` — was not
# installed. The line said passed. Two thirds of the app was not measured.
#
# ## Adding a line here is a decision, not a formality
#
# It says: this test cannot run in CI, and that is correct rather than merely convenient.
# If you are adding a line because the environment is missing something CI could install,
# install it in the workflow instead.
